Come si configura

Nel file .env del server (accanto a docker-compose.yml) vanno compilate:

EMAIL_HOST=smtp.tuoprovider.it
EMAIL_PORT=587
EMAIL_HOST_USER=info@aquaforma.space
EMAIL_HOST_PASSWORD=la-password
EMAIL_USE_TLS=true
DEFAULT_FROM_EMAIL=Aquaforma <info@aquaforma.space>

Per la fatturazione elettronica serve la stessa configurazione, ma con le credenziali della casella PEC: l'XML viene trasmesso allo SDI via PEC.

Dopo la modifica: docker compose up -d per riavviare con le nuove variabili.
